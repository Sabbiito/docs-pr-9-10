# Проєктна документація

Два документи проєктного рівня, підготовлені в межах практичної
роботи **DOCS**.

## System Specification Document (SSD)

[`System-Specification-Document.md`](./System-Specification-Document.md)

Технічна специфікація системи: архітектура клієнта й сервера,
функціональні вимоги (FR-1 – FR-12) та нефункціональні вимоги,
модель даних, специфікація зовнішніх інтерфейсів, обмеження й
припущення, трасування вимог до конкретних файлів реалізації та
тестів.

## Business Requirements Document (BRD)

[`Business-Requirements-Document.md`](./Business-Requirements-Document.md)

Бізнес-документ: контекст і проблема, яку вирішує продукт, бізнес-цілі,
зацікавлені сторони, бізнес-вимоги (BR-1 – BR-7) мовою очікуваного
результату (без технічних деталей реалізації), бізнес-правила,
критерії успіху, межі проєкту (out of scope), ризики та припущення.

## Як читати разом

SSD відповідає на питання «як це побудовано» — для розробника, що
працює з кодом. BRD відповідає на питання «навіщо це і для кого» —
для будь-кого, хто оцінює продукт з боку цілей і цінності, а не
реалізації. Документи навмисно не дублюють одне одного: кожна
бізнес-вимога в BRD має відповідну технічну вимогу в SSD (розділ 7
SSD, «Трасування вимог до реалізації»), але сформульована різною
мовою для різної аудиторії.
